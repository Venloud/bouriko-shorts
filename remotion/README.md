# Bouriko Remotion renderer

Media-first vertical Shorts renderer. React/Remotion controls scene timing, captions, free media and stock SFX. It does not use the old mascot presenter, Rock Phone overlay, Ken Burns/zoompan, or fade-to-black slideshow behavior.

Flow: story -> free media -> narrator WAVs -> stock SFX -> remotion_prepare.py -> Remotion 1080x1920 H.264 render.
