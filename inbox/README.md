# Inbox
Drop a .txt file here to jump the queue.
- First line `TOPIC` -> the next lines name a topic; the pipeline researches and writes it.
- First line `SCRIPT` -> exact lines to narrate, one per line, prefixed `BOURIKO:` or `ROCK PHONE:`.
  Aim for ~145 words so the video lands at 61-68 s without a long end card.
Optional: `NOT_BEFORE: 12` on line 2 = don't use before video #12.
