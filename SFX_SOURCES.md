# Bouriko SFX sources\n\nBouriko uses real downloaded sound effects only. There are **no procedural or generated tones**.\n\n## Source priority\n\n1. **Night Files (`Venloud/horror-shorts`)** — primary reusable library.\n2. **Mixkit** — fallback/additional source if a Night Files asset cannot be fetched.\n3. No effect — if neither source is available.\n\nThe Night Files repository contains a reusable SFX library including whoosh, camera shutter, UI click, notification, radio static, and impact assets. The build fetches the needed files at runtime rather than duplicating binary assets into this repository.\n\n| Bouriko effect | Night Files asset | Mixkit fallback |\n|---|---|---|\n| whoosh | assets/sfx/whoosh.mp3 | Mixkit ID 1490 |\n| sweep | assets/sfx/whoosh.mp3 | Mixkit ID 166 |\n| click | assets/sfx/ui_click.mp3 | Mixkit ID 1133 |\n| camera | assets/sfx/camera_shutter.mp3 | Mixkit ID 1430 |\n| interface | assets/sfx/ui_click.mp3 | Mixkit software interface start |\n| beep | assets/sfx/phone_notification.mp3 | Mixkit positive interface beep |\n| impact | assets/stings/default_impact.mp3 | Mixkit ID 2299 |\n| glitch | assets/sfx/radio_static.mp3 | Mixkit ID 2595 |\n\n### Source repositories\n\n- Night Files: https://github.com/Venloud/horror-shorts\n- Mixkit SFX: https://mixkit.co/free-sound-effects/\n- Mixkit license: https://mixkit.co/license/\n\nThe generated output/sfx_sources.json records which source actually supplied each file during a build. Raw SFX files remain build artifacts rather than being copied into the Bouriko repository.\n
